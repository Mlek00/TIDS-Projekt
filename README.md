Pomoč pri načrtovanju izletov


# Dokumentacija:
ARSO - pridobi meteorološke podatke in vremenska opozorila za Slovenijo. Aplikacija bo te podatke uporabljala za obveščanje/svetovanje uporabniku o vremenskih razmerah(vhod: izbran kraj in datum, izhod: vremenske razmere za naveden kraj ob navedenem datumu). dokumentacija na https://meteo.arso.gov.si/met/sl/service/

OPEN-Meteo - Weather Forecast API - za pridobivanje vremenskih napovedi za izbran kraj. Omogoča bolj podroben opis vremenskih razmer, dostopen na https://open-meteo.com/en/docs

OpenStreetMap - Overpass API - ob vnosu kraja, bo poiskal geografkse objekte("znamenitosti"), pridobljene z/na https://wiki.openstreetmap.org/wiki/Overpass_API , ki bodo nato predlagane uporabniku
